# Baker's Mobile Auto Detailing — Premium Rebuild

This rebuild keeps the existing Next.js App Router structure and WhatsApp quote flow, but refreshes the presentation around a premium automotive/editorial direction:

- Stronger first-screen value proposition and single primary conversion path
- Premium black / warm-white / acid-lime visual system
- More distinctive typography, gridlines, editorial spacing and motion
- Mobile-first navigation and CTA treatment
- Service cards, trust strip, process, social proof, FAQ and quote flow retained
- Gallery redesigned as a staggered editorial grid
- Concept imagery remains clearly marked in the gallery footer so real Baker's photos can replace it before launch

Run with `npm run dev` and deploy normally to Vercel.
